# Tøyenbadet for Home Assistant

Custom integration for keeping eye on the capacity at Tøyenbadet.

## Local development

Use the [Docker Compose test setup](dev/ha/README.md) to try the working-tree
integration in a separate Home Assistant instance with persistent test data.

Start it with `./dev/ha/run start` (or `sudo ./dev/ha/run start` if needed).
